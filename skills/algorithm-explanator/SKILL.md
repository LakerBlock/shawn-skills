## Example：两数之和

用户说"解释两数之和"且未指定方法 → 保存为 `1_两数之和.md`：

# 1 两数之和 Easy

## 题目链接
https://leetcode.cn/problems/two-sum/

## 一、问题分析
- **描述**：数组中找两数和为 target，返回下标
- **一句话理解**：找加起来等于目标的"搭档"
- **关键洞察**：对每个 x，只需知道 `target-x` 是否出现过

## 二、解法说明（哈希表）
- **方法**：哈希表一次遍历
- **为什么**：最简单，O(n)
- **思路**：边走边记账，看到新数就问"之前有没有人等着和我配对？"
- **变量**：`seen` 字典，键=数值，值=下标
- **循环**：单层 for，先查后存

## 三、完整图解
```
nums=[2,7,11,15], target=9
i=0,x=2: 查 seen[7]? 无 → 存 {2:0}
i=1,x=7: 查 seen[2]? 有=0 → 返回 [0,1] ✓
```

## 四、核心逻辑
```
complement = target - x
if complement in seen: return [seen[complement], i]
else: seen[x] = i
```
**关键**：先查后存，避免自配。

## 五、面试答题模板
"核心是快速判断另一半是否存在 → 哈希表 O(1) 查找 → 边遍历边存，查到立刻返回。"

## 六、完整代码
```python
def twoSum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
```

## 七、代码背诵

**三段式**：建字典 → 遍历查存 → 返回

**口诀表**：

| 代码 | 口诀 |
|---|---|
| `seen = {}` | 先开空账本 |
| `for i, x in enumerate(nums)` | 边走边看 |
| `if target-x in seen` | 搭档来过没？ |
| `return [seen[target-x], i]` | 配对就收工 |
| `seen[x] = i` | 没配上就记账 |

**填空模板**：
```python
def twoSum(nums, target):
    seen = ____
    for i, x in enumerate(nums):
        if __________ in seen:
            return [______________, i]
        seen[__] = __
```

**答案**：
```python
def twoSum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
```

**易错点**：

| 易错点 | 正确 | 错误 |
|---|---|---|
| 查存顺序 | 先查再存 | 先存再查（自配） |
| 返回值 | 下标 | 数值 |
| 字典方向 | 值→下标 | 下标→值 |
